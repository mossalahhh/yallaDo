# YallaDo – Graduation Project

YallaDo is a full-stack graduation project currently under development.  
The project consists of a **Node.js (Express)** backend and a **Flutter** frontend,
designed to work together as a scalable and maintainable application.

---

## 🛠️ Tech Stack

### Backend

- Node.js
- Express.js
- RESTful API architecture
- JWT Authentication (planned)
- Database integration (TBD)

### Frontend

- Flutter
- Cross-platform (Android / iOS)
- API-based communication with the backend
